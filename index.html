How to play

Add Person brings someone new into the gathering. They shake hands with each person already there.

Remove Person takes away the most recently added person and their connections. Reset starts the gathering over.

Watch the handshake counter and open Discover the Pattern to see how the totals grow. Try Challenge Mode to test what you have learned!

The mathematical secret

THE SECRET BEHIND HANDSHAKES

When everyone shakes hands with every other person exactly once, the totals follow the triangular numbers.

H = n(n − 1) / 2

H is the total number of handshakes and n is the number of people. We count pairs of people: each pair makes one handshake, and the division by 2 avoids counting the same pair twice.

Example with 5 people:
H = 5(5 − 1) / 2
H = 5 × 4 / 2
H = 20 / 2 = 10 handshakes

Each new person makes one handshake with every person already present. So the next person adds one more handshake than the person before them: 0, 1, 2, 3, 4…
